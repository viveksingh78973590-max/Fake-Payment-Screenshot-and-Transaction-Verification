About PayGuard AI

Problem: sellers hand over goods after seeing a screenshot, only to discover no money arrived.

Solution: analyse the screenshot for suspicious visual elements, then check the transaction details against a trusted payment record or authorised payment gateway.

Technology stack
  • Python + Django - backend, authentication, verification logic, dashboards
  • OpenCV + OCR (Tesseract) - image processing and field extraction
  • Machine learning (scikit-learn) - classify suspicious image patterns
  • HTML, CSS, Bootstrap, JavaScript - responsive frontend
  • SQLite / PostgreSQL - users, history, extracted data, audit records
Features
  • Payment Promise vs Reality - claimed amount, expected amount, screenshot status and the real provider record are compared
  • Explainable verification - every verdict lists the reasons and a risk score
  • Screenshot Family Tree - perceptual hashing links re-sent, cropped or edited copies
  • Fraud Chain - graph of user, screenshot, reference, provider and scam message
  • Payment Dispute Time Machine - timestamped evidence trail and CSV export
  • Fraud What-If Simulator - flip problems on and watch the real decision engine react
  • 3D voice bot - hover help, page intros, login guidance and a guided tour

The original browser-only PayGuard AI prototype is bundled too: open the offline demo (runs entirely in your browser, no server data).

A screenshot alone is never proof of payment. The ML score is only a supporting signal; the final decision always prefers verified provider data.
